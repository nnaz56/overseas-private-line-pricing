## 海外专线价格为什么查不到统一标准？先分清你在买什么

按目前市场的常见分法，主要有三档花费：

- **轻量跨境办公**：小型外贸团队用的轻量化方案，一年几百至几千元。
- **企业独享专线**：多人办公、需要独享带宽和固定 IP，通常按 5M、10M、20M、50M、100M 等独享带宽收费，进入万元/年级别。

## 同样叫专线，价格为什么能差几十倍？

差距来自计费方式本身。常见的计费维度有五个，任何一项变动，账单都会跟着变：

1. **带宽**：最主流的计费方式，带宽越大、网速越快，费用越高。做 TikTok 直播这类对速度敏感的业务，钱主要花在这一项。
2. **流量**：按实际使用流量计费，适合流量起伏大的业务，但单价通常比固定带宽高。
3. **覆盖地区**：跨境距离越远，网络建设和维护成本越高，美国、日韩、东南亚各方向的线路价格都不同。
4. **节点数量**：在新加坡、德国、美国各设一个接入点，每多一个节点加一笔钱；节点多的组网可以靠规模化分摊成本。
5. **增值服务**：独立 IP、专线优化、注册社交媒体账号用的独立线路等，都会增加总费用。

把每兆单价摊开看，差距更直观。三大运营商的主流报价大约在 400–500 元/M/月；多数企业 5M 起步，按最低价算，每月国际带宽成本至少 2000 元，一年 2.4 万——这只是 5M 的钱。境外站点不同，价格也不同：香港作为跨境的前哨，价格相对便宜；日本、韩国、新加坡、美国、德国、英国这些方向，大致在几百元/M 到 1 千多元/M。

轻量 SD-WAN 这边，市面上有低至 80 元/M/月的公开报价（不限流量、共享带宽和 IP 资源，以天下数据账号版为例）。同样按 5M 估算，一年大约 4800 元，和运营商独享专线差出数倍。

这里有个很多文章没讲透的点：**共享和独享不能直接比价**。80 元/M/月对应的是共享带宽的账号版玩法，适合个人和小团队；企业独享专线买的是独享带宽、固定 IP 和更高的稳定性保障，两者本来就不是同一种产品。拿共享版的价格去压独享专线的报价，谈不出结果。预算核定时先想清楚自己要哪一种，再去看 👉 [MKCloud 官网各档套餐的实时报价](https://bit.ly/mkcloud)，按同一口径对比才有效。

## 比价格更优先的问题：这条线拉得合不合规

合法接入国际专线只有两条路：向中国电信、中国联通、中国移动申请，或者找持有工信部电信业务经营许可（IP-VPN 类牌照）的第三方运营商办理。

两条路的差别很实际：

- **三大运营商**：物理专线接入，速度快、更稳定；但施工周期长、资费贵，一般中小企业很难接受，运营商本身也更多面向国企、事业单位受理这类业务。
- **持牌第三方 SD-WAN**：接入方式更多，价格低一截，综合性价比更高，是目前中小企业的主流选择。

合规流程上还有几件事容易被忽略。三大运营商通常会要求填表，承诺只访问哪些范围、不访问哪些；跨境专线一般按“公司本地站点—国内运营商机房—境外运营商机房—境外站点”的组网拓扑来受理，没有境外站点的公司可以用云站点充当境外端点。市面上无证的小运营商价格确实更便宜，但那不合规，有关部门一直在整治查处扰乱市场的行为——省下的专线钱，抵不上业务突然断线的损失。

签约前建议把这张清单过一遍：

1. 让对方出示电信业务经营许可，确认业务范围覆盖 IP-VPN/虚拟专用网类。
2. 问清带宽是独享还是共享，固定 IP 是否包含。
3. 确认计费周期和续费价，首年优惠价与次年起的价格差多少。
4. 把 SLA 写进合同。市面上有服务商公开承诺 15 分钟内响应、一般问题 3 小时内给出方案、重大故障 6 小时内处理，可以拿这个标准做参照。
5. 确认方案覆盖你需要的境外地区和节点数量，以及后续加节点的单价。

## 常见问题

### 海外专线为什么比普通企业宽带贵？

成本大头在境外基础设施。服务商要在境外落地城市有自己的 POP 点和带宽容量；没有自有 POP 点的服务商需要租用其他提供商的设施，费用会转嫁到报价里。采用的线路类型和网络协议也会影响成本。

### 5M 带宽够用吗？

对多数企业，5M 是起步配置。有硬件视频会议需求的话，建议单独组网并单独申请带宽，避免和视频专网抢资源；分支机构之间的虚拟互联可以用 MPLS 实现，分支拉低带宽、总部拉高带宽，整体成本更好控制。

### 去哪个方向的线路最便宜？

香港。它承担着跨境前哨的角色，价格相对便宜；日本、韩国、新加坡、美国、德国、英国等方向普遍在几百元/M 到 1 千多元/M。

### 更便宜的“灰色”线路能用吗？

无证经营不合规，市场正在被整治查处，一旦被查处断网，损失的是业务本身。要走稳妥路线，就在三大运营商和持牌第三方之间选。

### 公司没有境外站点，还能拉专线吗？

可以。境外端点可以用云站点代替，把云服务器作为境外的接入节点纳入组网。
